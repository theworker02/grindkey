# grindkey

Grind validation gates for key inputs before they hit prod.

**Site:** https://theworker02.github.io/grindkey/

## Install / run

```bash
git clone https://github.com/theworker02/grindkey.git
cd grindkey
node src/cli.js
node --test
```
